A lightweight Pomodoro Timer app built using **Vanilla JavaScript**, HTML, and CSS — designed to help you stay focused and productive.

## ✅ Features

- Customizable **Work** and **Break** durations
- Simple **Start** and **Reset** controls
- Theme toggle between **Light (☀️)** and **Dusky (🌙)** modes
- Displays completed Pomodoro cycles
- Responsive and mobile-friendly layout
- All functionality handled using plain JavaScript (no frameworks)

---

## 📌 How to Use

1. **Open the App**  
   Visit the [Live Demo]([https://your-deployment-url.com](https://pomodoro-timer-vanilla-js.vercel.app/)) in your browser.

2. **Set Work & Break Time**  
   - Use the input fields to enter desired work and break durations (in minutes).

3. **Start Timer**  
   - Click the **Start** button to begin your Pomodoro session.

4. **Reset Timer**  
   - Use the **Reset** button anytime to stop and reset the timer.

5. **Switch Theme**  
   - Tap the **☀️/🌙 icon** in the top-right to switch between light and dusky modes.

## 💡 About Pomodoro Technique

The **Pomodoro Technique** is a productivity method that uses a timer to break down work into intervals, traditionally 25 minutes of focused work followed by a 5-minute break.
